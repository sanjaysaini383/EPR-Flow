# EPRFlow

B2B SaaS for managing Extended Producer Responsibility (EPR) compliance in India under the Plastic Waste Management, E-Waste and Battery Waste Management Rules.

**Status:** Phase 0 (planning). See [docs/PHASE-0-PLAN.md](docs/PHASE-0-PLAN.md) and the draft schema in [prisma/schema.prisma](prisma/schema.prisma).

Setup instructions will be added in Phase 1.

> Regulatory values shipped in seed data are placeholders. **Verify them against the latest CPCB notification** before relying on any calculation.
